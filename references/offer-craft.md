# 谈判工艺：先报价 vs 后报价 + offer 全维度 + 实习场景特化

谈判**不是面试结束才开始的事**——它在你说"期望薪资"的那一秒就开始。这份 reference 教 skill 怎么把谈判从"被动接受"变成"协作设计"。

---

## 核心理念

**谈判 ≠ 讨价还价。谈判 = 协作发现一个双方都能接受的"组合解"**。

很多人把谈判当成"我多要 5k 你少给 5k"——这是 win-lose 心态。**真正的谈判在 offer package 的 30+ 维度里找互相可让步的组合**。

---

## 谈判的 3 个阶段

### 阶段 1 · 信号期（面试中）
对方在评估你时，你已经在埋谈判信号：
- 提其他面试 / offer 进展（社会证明 + 隐含损失厌恶）
- 主动问"团队这个 headcount 是急吗"（暴露对方的 BATNA 弱不弱）
- 反问"什么样的人是你最理想的 hire"（拿到对方的"理想画像"，谈判时往这个画像贴）

### 阶段 2 · 锚定期（HR 一面或 final HR）
HR 问"你期望薪资"时，**你的回答是整个谈判的锚**。
- 报得太低 = 锚永远拉不上来
- 报得太高 = 直接出局
- 报范围 + 条件化 = 安全 + 留谈判空间

### 阶段 3 · 让步期（offer 给到后）
HR 给出一个具体 offer，你要不要、怎么 counter。

---

## 锚定期：先报价 vs 后报价的两条剧本

### 剧本 A · 后报价（默认推荐）

**逻辑**：让对方先开口。对方先开口 = 你拿到了对方的真实带宽，你的锚永远不会比对方低。

**话术**：
> HR："你期望薪资是多少？"
> 你："我对薪资的看法比较 open——我更看重岗位本身和团队成长。所以更想了解贵司这个 level 的薪资带是怎么样的，我可以基于这个看是否合适。"

**为什么这么说**：
- 不显得 needy
- 把球踢回 HR
- "我更看重岗位本身" = 显示你不是 money-driven，让对方放心你不是来跳的
- "基于这个看是否合适" = 留了你拒绝的余地

**对方的几种回应**：

回应 1（理想）："这个岗位的范围是 X-Y 万。"
→ 你拿到了带宽，下一步说"X-Y 这个范围我可以接受，具体到我个人的话，结合我 [项目经验/学历/上家薪资]，我的期望落在 [Y 偏中上] 这个位置"。

回应 2（常见）："我们想知道你的期望，不希望你将就。"
→ 这是温柔的逼你先开口。你可以坚持 1 次："我理解。但我想了解贵司的范围是 (1) 出于尊重对方的 framework，(2) 我对市场带宽的了解可能和你们的实际情况有出入。如果一定要我先报，我希望落在 [一个高于市场中位数 10-15% 的范围]——具体可以再 align。"

回应 3（HR 不松口）："我们一定要你先说。"
→ 不要 hold 太久，给一个范围 + 留谈判空间："那我说一个范围吧——[偏高的下限] 到 [上限]。当然这个我可以基于具体岗位调整。"

### 剧本 B · 先报价（特殊场景）

**适用条件**：
- 你已经做过同公司同岗位的 levels.fyi / 看准 / 脉脉调研（有 B 级数据）
- 你有强 BATNA（已有竞争 offer）
- HR 显得没耐心或有时间压力

**话术**：
> 你："我目前手上有另一个 offer，base 是 X，加上其他部分总包 Y。考虑到贵司这边的成长空间，我希望总包能 match 或略高于 Y——具体可以一起看。"

**为什么管用**：
- 用"另一个 offer"做锚——锚是事实不是开口要价
- "考虑到成长空间"+"略高于"= 让对方看到你不是只为钱
- "一起看" = 协作姿态，不是对抗

**红线**：**不要谎报 offer**。HR 圈有时会暗中验证（前公司证明 / 同行打听），谎报代价可能是 offer 被撤。

## 让步期：counter offer 的工艺

### 拿到 offer 后的第一反应

**绝对不要**当场答应或拒绝——哪怕你心里 100% 想接。

**正确反应**：
> "非常感谢这个机会，我对这个岗位很感兴趣。我想花 [1-3 天] 仔细看一下整个 package 再回复你，可以吗？"

为什么：
- 不当场答应 = 留了 counter 空间
- 不当场拒绝 = 留了 walk away 后回头的空间
- 1-3 天 = 标准节奏，HR 不会觉得你在挑事

### Counter 的话术模板

```
"我对这个岗位非常感兴趣。
[感谢/positive 锚定 — 让对方知道你想签]

[肯定对方某些条件] —— 比如 [base/title/team] 我觉得很合理。
[具体表扬 1-2 个条件 — 互惠原则的应用，让对方更愿意为剩下的让步]

我想 align 一下 [具体维度] —— 我目前的 [BATNA / 期望 / 市场调研] 显示这一项落在 [更高数字] 会更对得上。
[具体可量化的 counter — 不抽象]

如果这一项可以调整，我可以 [今天/明天] 签。
[条件化承诺 — 给对方一个明确的 close 路径]"
```

### 反例

❌ "你给的太低了，市场行情是 X" —— 对抗姿态，没用 BATNA，对方会防御。
❌ "我能不能再 push 一下？" —— 模糊，没具体数字。
❌ "我要 100w 总包" —— 没解释、没条件、显得贪。
❌ 一直沉默不回 —— HR 会撤 offer 给下一个候选人。

## offer 全维度（不只看 base）

很多人谈判只盯 base salary——这是错的。Total comp 是 30+ 维度的组合。**当某一维不能动时，别的维度可能能动**。

### 现金部分
1. **Base salary**（月薪 × 12 或 13）
2. **Bonus**（年终，通常 base 的 0-50%）
3. **Sign-on bonus**（一次性签字费，通常分 1-2 年发放，离职要退）
4. **Relocation**（搬迁补贴，跨城市常有）

### 股权部分
5. **RSU 总数 + vesting schedule**（4-year-cliff 是标准，但 cliff 长度、grading 比例可谈）
6. **Refresher**（年度新增）
7. **Sign-on grant**（额外股权奖励）
8. **Fast vesting**（针对 cliff 期前离职的保护，少有但可争取）

### 时间部分
9. **Vacation days / 年假**
10. **Parental leave / 育儿假**
11. **Work hours flexibility**（弹性上下班 / hybrid 比例）
12. **Personal days / sick days**

### 角色部分
13. **Title**（职级 / 头衔）
14. **Scope**（你 own 哪个产品线/团队）
15. **Team / manager**（你的直属是谁——这个**至关重要**，可以要求 "I want to meet my manager before signing"）
16. **Headcount**（你能 hire 多少人）
17. **Reporting line**（你向谁汇报）

### 学习/发展部分
18. **Learning budget**（培训/课程/会议预算）
19. **Conference budget**
20. **Mentorship**（指定 mentor）
21. **Sabbatical**（长假，少有但有些公司给）

### 福利部分
22. **Health insurance**（中国国内主要看商业保险）
23. **Visa support**（外企/海外）
24. **Equipment**（电脑/外设）
25. **Meal stipend / 餐补**
26. **Gym / 健身**
27. **Commute support**（交通补贴）

### 退出条件
28. **Notice period / 离职提前期**
29. **Non-compete clause**（竞业协议——重要，可争取缩短或要求竞业补偿）
30. **IP assignment terms**（你的副业产出归谁）

### 实习场景额外维度
31. **转正路径明确度**（口头 vs 邮件确认）
32. **转正面试流程**（要不要再走完整流程，还是简化）
33. **每周天数 / 总时长**（4 天 vs 5 天）
34. **远程比例**
35. **实习生津贴**（住宿 / 餐补）

### 谈判优先级（按可让步性排）

**最容易让步的**（可作为 counter 重点）：
- Sign-on bonus（公司给一次性钱比抬 base 容易得多）
- RSU sign-on grant
- Title（小幅升一级很常见）
- Vacation days
- Start date（你能延后入职 = 公司喜欢，但你也可以借机谈别的）

**中等让步可能**：
- Base salary（5-15% 区间内有谈判空间）
- Bonus 比例
- 转正路径（实习场景）

**最难让步的**：
- 远低于市场的 base 想拉到中位数（结构性问题）
- Title 跨级（违反 leveling 体系）
- Non-compete（公司要保护商业利益）
- Headcount（涉及预算分配）

## BATNA / ZOPA 概念（隐藏在话术里）

### BATNA = Best Alternative To Negotiated Agreement
**你最好的备选方案**。BATNA 越强，谈判越有底气。

谈判前自评：
1. 我手上有几个其他 offer / 进度？
2. 我现在的工作能不能继续做（如果我不接这个 offer）？
3. 我多久之内必须要 offer（学生：毕业前；社招：通常 1-3 个月）？

### ZOPA = Zone Of Possible Agreement
**双方可能达成协议的区间**——你的最低价 ↔ 对方的最高价 之间的重叠。

谈判的本质是：发现 ZOPA + 在 ZOPA 内争取靠近你想要的位置。

不需要在话术里说"我的 BATNA / ZOPA 是 X"——但你心里要清楚。

### 三档对比："你期望薪资"

**弱**："薪资我没要求，按公司标准来。"
- 弱 BATNA + 没锚 + 显得 needy

**合格**："我希望 base 在 X 万到 Y 万。"
- 有锚但没说为什么，谈判空间窄

**惊艳**：
> "我对薪资比较 open——更看重岗位 fit 和成长空间。具体到数字，我目前的判断是基于这几个 inputs：(1) 我看了下 levels.fyi 和看准上 [类似岗位类似经验] 的中位数大概在 X 区间；(2) 我现在手上的另一个 offer 是 Y；(3) 这个岗位 JD 描述的工作内容比我之前做过的多了 [一个具体维度]，我觉得有 5-10% 的溢价合理。
>
> 综合下来，我希望落在 [Y + 10%] 到 [Y + 20%] 之间。当然如果其他维度（比如 sign-on 或 RSU）有空间，base 可以再聊。"

为什么惊艳：
- 显示**你做了 research**（A 级源 levels.fyi）
- 用了**两个锚**（市场 + 已有 offer）
- 给了**理由**（多了一个维度）
- 留了**让步空间**（"其他维度有空间 base 可以再聊"——直接告诉对方"我可以在 sign-on 让步换 base"）
- 全程没显得 needy，也没显得贪

## 实习场景特化

实习生薪资透明度高（日薪 200-350 范围内），**实习"谈判"的真正主战场不是钱，是**：

### 可谈维度（按重要性）

1. **转正路径** ⭐⭐⭐⭐⭐
   - 转正面试是再走一遍完整流程，还是简化？
   - 转正 offer 的级别和直接校招的差异？
   - 转正的具体要求是什么（数据驱动 vs 老板拍板）？
   - **建议**：要求邮件确认转正流程的关键条款，不只是口头。

2. **导师 / mentor** ⭐⭐⭐⭐
   - 我的直属 mentor 是谁？
   - 我入职第一周能见到 TA 吗？
   - **关键**：好的实习导师 vs 坏的差距巨大，等于"实习的全部价值"。

3. **项目分配** ⭐⭐⭐⭐
   - 我会被分到什么项目 / 业务线？
   - 是核心项目还是边缘？
   - **建议**：可以问 "我加入后能 own 一块还是协助" —— 答案直接决定你简历能写什么。

4. **每周天数** ⭐⭐⭐
   - JD 写 4 天/周——你能做到吗？
   - 5 天 vs 4 天对总时薪和经验值差异巨大。

5. **远程比例** ⭐⭐
   - 完全 onsite vs hybrid vs 全远程？

6. **日薪 / 月薪** ⭐⭐
   - 日薪在标准范围内（200-350）通常没什么谈
   - 但可以问"如果我有特殊原因（房租压力 / 通勤）能不能略高"——值得一试

7. **食宿补贴** ⭐
   - 互联网大厂通常有，但要确认

### 实习 counter 话术（针对火山方舟）

> "非常感谢这个机会。整体我都很满意，想 align 两个点：
>
> (1) **转正路径**——能否在 offer 里明确写一下转正的流程和要求？我希望知道我加入后做到什么样可以走转正流程，这样我能更聚焦目标。
>
> (2) **mentor 安排**——我能否在入职前和我的 mentor 通一次电话？我想了解 TA 对我前 30/60/90 天的期待，以便我提前准备。
>
> 这两点如果能确认，我今天就可以签。"

注意话术做对的：
- 要的不是钱（实习 base 不好谈）
- 要的是**"软性资产"——转正确定性 + mentor**（这才是实习的核心价值）
- 给了 close 路径（"今天就签"）—— 互惠让步信号

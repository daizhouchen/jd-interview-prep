# 场域分析：公司在 AI 行业的位置

JD 解码完是"这个岗位要什么"。但你面试时面对的不是 JD，是**一群有特定文化基因的人**——他们说什么话、用什么术语、在意什么、害怕什么——这是**场域**。Bourdieu 说，进入一个场域要带对的"文化资本"。这份 reference 教 skill 怎么读懂目标公司这个场域。

---

## 三个分析维度

### ① 公司在 AI 行业的位置坐标

按两个轴打坐标：
- **横轴**：基础模型自研 ←→ 应用层
- **纵轴**：B 端 ←→ C 端

```
              C端
               │
  豆包/Kimi   │  各种 AI 应用 / Agent 产品
  (字节/月暗) │
   ─────────────────────────────  应用层
               │
   通义/文心  │  火山方舟 / 百炼 / 千帆 / API 平台
  (阿里/百度)│  (面向开发者和企业的 MaaS)
   GLM/Doubao │
  ─────────────────────────────
               │
               B端
   ←—— 自研模型 ——→ ←—— 应用工具/平台 ——→
```

定位决定面试侧重：

| 象限 | 公司例 | 面试重点 |
|---|---|---|
| 自研 + C 端 | 月暗 Kimi、Minimax 海螺、字节豆包 C 端 | 用户增长 / 留存 / DAU / 产品 sense |
| 自研 + B 端 | 通义 / 文心 / GLM API | 模型能力包装 / 行业方案 / 大客户成功 |
| 平台 + B 端 | 火山方舟 / 百炼 / 千帆 / 百川企业版 | 平台化产品力 / 开发者体验 / 生态 / 行业 SaaS |
| 应用 + C 端 | 妙鸭 / 即梦 / 通义万相 | 内容创意 / 用户场景挖掘 / 增长 |

### ② 派系（这是社会学的"惯习"层）

中国 AI 公司大致分三大派系，**说话方式不同、关心的问题不同、面试官的暗藏偏好不同**：

#### 北美派（在华外企 / 北美归来创业）
- 代表：Anthropic 中国团队、OpenAI（无中国岗但参考）、北美归国创业（如 Pika 创始团队系）
- 黑话：grounding / agentic harness / constitutional / eval-driven / safety-first / north star metric / leverage
- 关心：模型能力的本质边界、AI safety、long-horizon agent、RLHF/RLAIF、interpretability
- 面试官偏好：**有判断、有审美、英文流利、读论文、引用 Anthropic/OpenAI 博客**
- 不喜欢：纯业务话语（"GMV" "增长黑客" "私域转化"）

#### 字节系 / 阿里系 / 大厂派
- 代表：字节豆包/火山方舟、阿里通义/百炼、腾讯混元、百度文心
- 黑话：底层逻辑 / 抓手 / 颗粒度 / 闭环 / 拉通 / 对齐 / OKR / 双月 / 复盘 / 行业 know-how
- 关心：业务增长、行业落地、客户标杆、ROI、规模化、合规
- 面试官偏好：**结构化、能扛事、复盘能力、能讲清"我做了什么 + 数据是什么 + 怎么复盘"**
- 不喜欢：纯学术话语（"我读了一篇论文觉得很有意思"）、没数据支撑的判断

#### 创业派（独立 AI 创业公司）
- 代表：月之暗面、Minimax、智谱、零一、阶跃、面壁、深度求索
- 黑话：split 各家不同——但共性是"模型 + 产品 + 增长"三位一体
  - 月暗：长上下文 / Kimi-K 系列 / Coding / Agent
  - Minimax：海螺视频 / 多模态 / Talkie
  - 智谱：ChatGLM / GLM-4 / 企业版
  - 零一：Yi 系列 / API / 海外
  - 阶跃：Step 系列 / 多模态 / 生产力
- 关心：增长 + 模型差异化 + 商业模式跑通
- 面试官偏好：**0→1 经验、能 own、思考密度大、对模型/产品/增长都懂一些**
- 不喜欢：纯大厂打工仔思维（"我等 leader 派活")

### ③ 最近动作的解读（核心：从公开信息反推战略意图）

**WebSearch 必拿的 5 类情报**：

1. **最近 3-6 个月产品发布**
   - 出新模型 → 在哪条赛道押注？例：火山方舟 Coding Plan 2026 → 押注 AI Coding 赛道
   - 出新功能 → 战略上是攻还是守？
2. **融资 / IPO 动态**
   - 刚融 → 扩张期，团队会大量招人，可以谈机会成长性
   - 没融 → 谨慎期，每个 hire 都要 ROI 极清楚
3. **核心高管/leader 公开发言**
   - 创始人说什么是 Q1/Q2 重点 → 你面试的岗位往这上面靠
   - leader 在播客/采访里强调什么 → 那是面试时的"文化对齐点"
4. **技术博客 / 开发者社区**
   - 公司技术博客最近主推的概念 → 例：火山引擎社区主推"Agentic RAG"，意味着面试火山方舟岗位时这个概念要熟
   - 开发者社区有什么开源项目 → 暴露技术品味
5. **招聘节奏**
   - 同一岗位多个城市同时招 → 团队在快速扩张，岗位有上升空间
   - 只在某一城市招 → 团队在收缩或单点突破

## WebSearch 策略（Step 1 公司情报必跑）

调 3-5 次，每次目标不同：

```
Search 1: <公司名> <部门或产品线> 2026 战略 / 最近动态
Search 2: <公司名> 创始人/CEO 最新发言 / 采访 / 内部信
Search 3: <公司名> <岗位关键词> 技术博客 / 开发者社区
Search 4: <公司名> 最近融资 / IPO / 业绩
Search 5: <公司名> <竞品名> 对比 / 行业分析
```

**所有结果必须标置信度**：
- **A** = 公司官方源（官网公告、CEO 公开信、技术博客原文）
- **B** = 主流财经/科技媒体（36氪、晚点 LatePost、The Information、第一财经、科技日报、IT 桔子）
- **C** = 二手社区（知乎、小红书、Reddit、X、脉脉）
- **D** = 你的推断（基于 JD 措辞 + 行业常识，未直接证实）

## 反例：错误的场域分析

❌ "这家公司是字节旗下的，可能比较卷" —— 没情报，纯刻板印象。
❌ "建议你了解一下这家公司的业务" —— 废话，没有具体动作。
❌ 把 5 年前的新闻当成"最近动作" —— 失效情报比没情报更危险。

✅ "火山方舟在 2026 年 4 月推出了 Coding Plan，全面兼容 Cursor/Claude Code/Cline 等十几款编程工具——这意味着团队当前的战略重心从'通用 MaaS'向'AI 编程开发者生态'倾斜。你面试的'AI Application 解决方案'岗虽然主打企业落地，但**对 Coding Plan 这条赛道有基础认知会让你显得'懂团队的当下重心'**。" —— 这才叫场域分析。

## 火山方舟特化情报库（示例，用 e2e 测试）

> 此节作为 skill 内部参考——当 JD 来自火山方舟时，可直接调用以下情报作为 A 级源。其他公司类似维护需 WebSearch。

- **公司**：字节跳动 / 火山引擎 / 火山方舟
- **行业坐标**：平台型 + B 端，介于"自研"（豆包）和"应用层"之间。火山方舟本身是 MaaS 平台，搭载豆包+业界主流模型。
- **派系**：典型大厂派（字节系），关键词："数据驱动""ROI""复盘""坦诚清晰"
- **2026 关键动作（A 级源 volcengine.com）**：
  - Coding Plan 全面兼容 Cursor / Claude Code / Cline
  - Seedance 2.0 视频生成开放（影视/漫短剧/广告）
  - 汽车 AI 方案：豆包大模型搭载 700+ 万辆车
  - 安全资质：ISO/IEC 42001 + 等保三级 + 信通院可信云
- **技术博客主推概念**：Agentic RAG（火山引擎开发者社区有原文）、VikingDB（亿级向量检索）、AI Search、视频理解
- **战略意图**：从"中国 MaaS 份额第一"向"AI Native 开发者生态 + 行业垂直深度"双线推进
- **面试这个岗位（AI Application 解决方案 PM 实习）真正在找的人**：
  - 能把模型能力翻译成行业语言
  - 能配合解决方案 sales 闭环交付
  - 能写好的 PPT 和方案文档（JD 明确写了"PPT 和方案总结能力较强者优先"）
  - 懂 RAG/知识库/Agent 但不需要造模型

# 解码 JD：表层期待 / 隐含期待 / 避雷信号

JD 是**高密度信号源**。大部分人只读到第一层（要会什么技能），但隐藏的第二层（这家公司这个团队真正在缺什么人）和第三层（这份 JD 在向你发警告）才决定面试输赢。

这份 reference 教 skill 怎么把一份 JD 拆成三栏，每条建议都扣回原文具体词句。

---

## 三栏框架

### 表层期待（What they say）
JD 字面写的"职位要求"和"职位描述"——硬技能、软技能、学历、年限。

提取要点：
- **硬技能**：技术栈/工具/方法论的具体名词（如 LLM、RAG、向量数据库、Prompt、Agent、PE、SQL、Python、PPT）
- **软技能**：抽象能力词（如"逻辑思维""客户服务意识""执行力""责任心""沟通"）
- **学历/经验门槛**：硕士/本科/N 年/在校生/毕业 X 年内
- **业务方向**：B 端/C 端、电商/视频/新闻/汽车、平台型/应用型

### 隐含期待（What they really need）
JD 字面没说但**通过结构和措辞暴露**的真实需求。识别方法：

| 信号 | 推断 |
|---|---|
| 多次出现"客户"、"交付"、"沟通" | 这是 GTM/解决方案岗，不是纯产品岗，重点不是 0→1 而是 1→100 落地 |
| 出现"行业最佳实践"、"标杆案例" | 公司现阶段在打造行业护城河，需要会做案例包装的人 |
| 写"协助"、"配合"、"支持" | 实习/初级岗，不要在面试里表现得太"主导"——要展现"借力打力"的能力 |
| 写"梳理"、"完善"、"迭代" | 这是存量优化岗，不是开荒岗，过度强调"破局/创新"反而错位 |
| 出现"项目管理"、"答疑" | 需要客户成功（CSM）属性，不只是 PM |
| 出现"见客材料" | 面试时强调你的 PPT/方案输出能力是高 ROI |
| 业务列了 4-5 个垂类方向 | 团队正在多线作战，对**通用方法论 + 跨场景迁移能力**评分高 |
| 一条业务都不写、只列能力要求 | 团队方向待定/换 leader，回答时不要押注某个具体方向 |
| 强调"算法应用"而不是"算法研究" | 不需要会训模型，需要会**用模型解决业务问题**——这是 AI PM 不是 ML 工程师 |

### 避雷信号（What they're warning about）
JD 里隐藏的红旗。识别这些**不是**为了让用户不去——是为了**面试时的策略性应对**。

| 信号 | 红旗解读 | 面试策略 |
|---|---|---|
| "适应快节奏"、"抗压"、"需要快速学习" | 团队人手不足/项目交付压力大/可能 996 | 准备一个"我在压力下怎么排优先级"的故事，但**不要**主动问加班 |
| "高度自驱"、"自我驱动" | 管理体系弱/leader 不带人/可能没明确 OKR | 准备"我怎么在模糊环境下定义自己工作"的案例 |
| "灵活应变"、"快速试错" | 战略不稳定/方向常变 | 准备"项目方向被砍后我怎么处理"的故事 |
| "扁平化"、"快速决策" | 可能扁平化变成"老板说啥就是啥"——决策权高度集中 | 反问环节问"过去 6 个月最大的方向调整是什么？"以确认 |
| "全栈能力"、"多面手" | 一个人当三个人用 | 准备"我怎么 prioritize" 的故事；薪资谈判时用这点抬价 |
| "保密协议要求高"、"不能对外披露" | 业务敏感/合规问题/或纯属保密文化重 | 反问问"对外可分享的范围是什么"——这一问还显示你懂合规 |
| 反复出现"主人翁"、"owner 意识" | 责任>权限的文化（你要扛事但权限不大） | 准备"我没有正式权限但推动跨团队协作"的故事 |
| 没写薪资带 / 写"具有竞争力" | 通常意味着低于市场或谈判空间被压缩 | 准备 BATNA，不要先开口 |
| 实习"持续 6 个月以上"、"每周至少 4 天" | 把实习当用工 | 接受这个前提，但反问要点出"转正路径"——见 offer-craft.md |

## 级别推断（基于 JD 措辞）

JD 写的"实习"vs"P5"vs"P7"会带来完全不同的面试期待。识别信号：

### 实习（Intern）
- 关键词：在校生 / 实习 / 6 个月 / 每周 4 天 / 协助 / 配合 / 支持
- 期待：**学得快 + 能干活 + 不出错**。重点不是创新，是 reliability。
- 不要：在面试里展现"我有更好的想法重做一遍"——你是来学习+干活的
- 要：展现"我能很快上手 + 我不会成为团队负担"——这是隐性评分点

### Junior（P4-P5 / 校招正职）
- 关键词：1-3 年经验 / 独立负责 / 推动落地 / 沉淀方法论
- 期待：能独立 own 一块业务，但需要 leader 兜底
- 重点展现：**结构化思考 + 复盘能力**

### Mid（P5-P6 / 3-5 年）
- 关键词：定义产品 / 跨团队协作 / 行业洞察 / 战略规划
- 期待：能定义问题 + 拉通资源
- 重点展现：**非显然的判断 + 商业 sense**

### Senior（P7+ / 5 年以上）
- 关键词：前沿方向 / 行业影响力 / 团队搭建 / 标杆案例
- 期待：能定方向 + 带团队 + 对外输出
- 重点展现：**远见 + 体系思考 + 行业话语权**

## 薪资带推断

JD 多半不写薪资，但能从结构推：

| 信号 | 推断 |
|---|---|
| 大厂 + 实习 + 北京/上海 | 日薪 200-350 RMB（互联网大厂 AI 方向）/ 200-300（其他） |
| 创业公司 + 实习 + AI 方向 | 日薪 150-250 RMB，部分头部如月之暗面/Minimax 接近大厂 |
| 大厂 + 校招正职 + AI PM | 总包 30-45w（北上深，2026 行情） |
| 大厂 + 社招 P6 + AI PM | 总包 60-100w |
| 大厂 + 社招 P7 + AI PM | 总包 90-150w |
| 创业公司 + 同级 | 现金部分通常少 20-30%，期权未必能兑现，按 D 级置信度看待 |
| JD 标"具有竞争力" | 至少不要低于市场中位数；不开口先报价 |
| JD 标具体范围 | 通常报范围中下值，留谈判空间 |

## 输出格式（给 HTML 用）

skill 在 L1 战略层输出 JD 解码时，按这个结构出三栏：

```
🎯 JD 表层期待（字面要求）
- [硬技能 1] —— JD 原文："xxx"
- [硬技能 2] —— JD 原文："xxx"
- [软技能 1] —— JD 原文："xxx"
...

🔍 JD 隐含期待（藏在结构里）
- [推断 1] —— 依据：JD 多次出现 "xxx"，结合岗位是"产品解决方案"，推测真实期待是 [...]
- [推断 2] —— 依据：[...]
...

🚩 JD 避雷信号（红旗 + 应对）
- 信号：JD 写"xxx"
  红旗解读：[...]
  面试策略：[...]
...

📊 级别 + 薪资推断
- 级别：[实习/Junior/Mid/Senior]，依据 [...]
- 薪资带（推断）：[...] 置信度 [B/C/D]
```

每条**必须引用 JD 原文**——这是防止"通用化漂移"的关键。如果某条没办法扣回 JD 原文，删掉它。

## 反例：错误的 JD 解码

❌ "这家公司在做 AI，岗位需要会用大模型" —— 太泛，所有 AI 岗都这样。
❌ "这是个好机会，建议你准备 LLM 相关的面试题" —— 没扣 JD 原文，没分层，没策略。
❌ "JD 提到'抗压'，所以你要表现得很能抗压" —— 把红旗当要求看，错失策略性应对。

✅ "JD 写'负责跟进重点客户，配合推动达成合作，树立行业标杆案例'——这一句话告诉你三件事：(1) 这是 GTM 岗不是产品创新岗；(2) 公司现阶段在卷'标杆案例'，需要会做客户故事的人；(3) 实习生的角色是'配合'，不是主导，面试别表现成 leader 范，要表现'借力'的能力。"

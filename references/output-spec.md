# HTML 作战地图输出规范

最终交付物是一份**单文件 HTML**（典雅风），用户可以离线打开、打印、带去面试现场。这份 reference 规定 HTML 的**章节结构、风格、信息密度**。

---

## 总原则

1. **单文件**——所有 CSS、JS 都内联，不依赖外部资源（除字体可用 Google Fonts CDN）
2. **典雅风**——黑白 + 一个主色（按公司选）+ 衬线/思源字体（中文用思源宋体或仓耳今楷，英文用 EB Garamond / Lora）
3. **可折叠**——所有非核心章节用 `<details>` 折叠，避免初次打开就被信息淹没
4. **TOC 固定**——左侧或顶部固定一个章节导航
5. **可打印**——确保 print stylesheet 让 HTML 打印出来也舒服
6. **palette**——主色按公司提取（火山方舟 = 橙红 #E64340、字节 = 蓝 #3370FF、阿里 = 橙 #FF6A00、Anthropic = 米色 #D4A574 等）

---

## 章节结构（按顺序）

```
1. 封面（标题 + 公司 + JD 简要 + 日期）
2. 元认知诊断 ⭐⭐⭐ [必读，不折叠]
3. 战略层 [L1]
   3.1 JD 解码（表层 / 隐含 / 避雷）
   3.2 场域分析（公司位置 / 派系 / 最近动作）
   3.3 叙事主轴 + 3 个传递目标形容词
   3.4 黑话校准卡
4. 战术层 [L2]
   4.1 分轮次画像（按推断的轮次链 N 张卡）
   4.2 AI PM 考题域（命中的 3-5 个考点 + 认知地图 + 三档对比）
   4.3 项目深挖（用户每个项目 3 层讲法）
   4.4 行为题（4-6 题三档对比）
5. 话术层 [L3]
   5.1 自我介绍 30s/60s/2min
   5.2 反问清单（4 层 × 4 题）
   5.3 谈判剧本（锚定期 + 让步期 + counter 模板）
   5.4 面试前 24h / 1h 清单
   5.5 面试中 3 个核心动作 + 应对"我不会" + 压力面
   5.6 面试后 retro + follow-up 邮件模板
6. 紧急时刻速查（一页纸：核心话术 + 必避雷）
7. 附录（公司情报源 + 简历 echo）
```

## 各章节的写作要求

### 元认知诊断（200-300 字，第一段）

**这是 HTML 第一眼看到的内容，直接决定整份地图的"调性"。**

写作要求：
- 不要寒暄（"祝你面试顺利"是最差开头）
- 直接给"你这场面试的真相"
- 必须包含 3 个要素：
  1. **简历过了说明 X 已被预设达标，所以接下来对方真正在评 Y**
  2. **这家公司这个岗位面试的隐含规则是 [...]**
  3. **你的 1 句话主轴是 [...]**

#### 示范（针对火山方舟 AI App 实习）

> **你这场面试的真相**
>
> 你的简历过了说明 *基础 AI/LLM 知识 + 算法应用经验* 已经达标——所以接下来 1-2 轮面试对方真正在评的是 **"你能不能在客户语境里翻译模型能力"**。
>
> 火山方舟做的是 B 端 MaaS + 行业方案，**这个岗位的隐含规则是：你不是来做模型创新的，你是来做客户落地的**。所以面试官最在意三件事——(1) 你懂 RAG/Agent 但更懂客户场景如何落地；(2) 你能扛得住客户 IM 的来回；(3) 你写得出能让 sales 直接拿去见客的 PPT。
>
> 你的 1 句话主轴："**我一直在做'把模型能力翻译成行业语言'这件事——研一做过医疗 RAG，最近在帮电商客户做 PoC，火山方舟把豆包 + VikingDB 这套能力下沉到电商/视频/新闻这些垂类，正是我的'翻译' 能力能规模化的下一站。**"
>
> 后续所有内容围绕这条主轴展开——记住：**你不是来证明自己懂模型的，你是来证明自己懂客户怎么用模型的。**

### JD 解码

格式按 decode-jd.md 的输出格式。**每条扣 JD 原文**，无原文出处的删掉。

### 场域分析

格式按 decode-field.md 的输出格式。**所有公司情报标 A/B/C/D 置信度**。

### 叙事主轴

格式按 narrative-architecture.md 的输出格式。**3 个形容词每个有"反推应对"**——告诉用户每个形容词怎么在面试中具象化。

### 分轮次画像

按 round-strategy.md 输出。**根据 JD 推断轮次链**：实习通常 1-2 轮，正职通常 3-5 轮。每轮一张卡。

### AI PM 考题域

按 ai-pm-canon.md 的命中规则选 3-5 个考题，每个出认知地图 + 三档对比。**认知地图用 ASCII art 渲染**（HTML 用 `<pre>` 保格式）。

### 项目深挖

如果用户给了简历，对每个 AI 相关项目输出 3 层讲法。如果没给简历，输出占位："`[需要你的简历]：把你的项目按 narrative-architecture.md 的'3 层讲法'格式自己填充`"——并在元认知诊断章节提醒"建议提供简历后重跑 skill"。

### 行为题

按 behavioral-craft.md 选 4-6 题，每题三档对比。

### 反问清单

按 questions-you-ask.md，4 层 × 1 题。每题附"对方可能这样答 + 你的'接' 动作"。

### 自我介绍 + 谈判 + 仪式

各按对应 reference 输出。

### 紧急时刻速查（"一页纸"）

最后放一个**精简到极致的 cheat sheet**，方便用户面试前 5 分钟看：

```
🚨 面试前 5 分钟看这个

【主轴】[1 句话]
【3 个形容词】[3 个]
【自我介绍 30s】[完整文本]

【高频题应对】
- "为什么选我们" → [一句关键钩子]
- "最大的失败" → [一句关键钩子]
- "你怎么看 [行业话题]" → [一句关键钩子]

【4 个反问】
1. [一句]
2. [一句]
3. [一句]
4. [一句]

【必避雷】
🚫 [一句]
🚫 [一句]
🚫 [一句]
```

## HTML 风格要求（具体实现）

### 配色方案（按公司主色定制）

```
火山方舟（橙红主色）:
  primary: #E64340
  secondary: #1F2329
  text: #1F2329
  text-muted: #6F7782
  bg: #FAFAFA
  bg-card: #FFFFFF
  border: #E5E6EB
  accent-soft: #FFF1EE

字节（蓝主色）:
  primary: #3370FF
  ...

通用回退（暖灰主色）:
  primary: #594A3C
  ...
```

### 字体

```
中文：思源宋体 / Source Han Serif / Noto Serif CJK SC
英文：EB Garamond / Lora / Crimson Text
等宽：JetBrains Mono / Fira Code（用于 ASCII 认知地图）
```

### 排版尺寸

```
正文行高：1.7-1.85
段落最大宽度：680px
段落间距：1.4em
H2 章节顶部：3em
TOC：左侧固定，280px 宽，背景浅
正文内边距：左右 64px / 上下 48px
```

### 三档对比的样式

用 3 列卡片：弱（灰）→ 合格（中性）→ 惊艳（主色高亮）。每张卡顶部小标签 + 主体文本。

### 反例的样式

用斜杠红色边框 + 🚫 emoji 前缀。和正常段落明显区隔。

### 认知地图

用 `<pre>` + 等宽字体渲染 ASCII。在 HTML 里给一个浅色背景框。

### 折叠章节

```html
<details class="fold">
  <summary>章节标题（点击展开）</summary>
  <div class="fold-body">
    内容
  </div>
</details>
```

默认**只有 4.x（战术层）和 5.x（话术层）的子章节折叠**——元认知诊断 + 战略层都默认展开。

### 顶部 Sticky TOC

```html
<aside class="toc-sticky">
  <nav>
    <a href="#meta">元认知</a>
    <a href="#l1">战略层</a>
    <a href="#l2">战术层</a>
    <a href="#l3">话术层</a>
    <a href="#cheat">速查</a>
  </nav>
</aside>
```

### 可打印

```css
@media print {
  details, .fold-body { display: block !important; }  /* 全展开 */
  .toc-sticky { display: none; }  /* 隐藏导航 */
  body { font-size: 10pt; }
  h2 { page-break-before: always; }
}
```

## 反例（不要这样做）

❌ HTML 第一段写"你好，欢迎使用面试准备工具" —— 元认知诊断不见了
❌ HTML 输出 5 万字、什么都堆 —— 信息密度低 = 没用
❌ 配色用 AI slop（紫蓝渐变 + emoji 满屏）—— 不是"AI 风"，要"典雅风"
❌ 三档对比用同样长度的描述 —— "惊艳"档应该明显比"弱"档丰富
❌ 反问环节给 12 题 —— 一场面试只问 3-4 题，多了就是浪费

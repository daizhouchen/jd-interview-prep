# 仪式两端：面试前 / 当天 / 面试后

面试**不是从"你好"开始的**——是从前一晚开始的。**也不是"再见"结束的**——是 follow-up 邮件之后才结束。

这份 reference 教 skill 怎么把"面试这件事"作为一个完整仪式来经营，而不只是面对面那 60 分钟。

---

## 面试前 24 小时

### 内容准备清单（晚上做）

- [ ] 重读 JD 一遍，**用红笔标注 5 个关键词**（这些词在面试中你要主动 echo）
- [ ] 重读你的简历，**在每个项目旁写 3 个深问点**（面试官最可能从哪 3 个角度切入）
- [ ] 重读你的"叙事主轴" + "3 个传递目标形容词"（见 narrative-architecture.md）
- [ ] 把"自我介绍 30s/60s/2min"3 档**对着手机录一遍**——听一下哪里别扭
- [ ] 准备 6-8 个反问，按"4 层 × 现场选 4 题"的方式排好
- [ ] 用 ChatGPT 或 Claude 做一次"模拟面试官"：让 AI 用 5 个最难的问题问你（"你觉得 [我简历里的项目] 最大的弱点是什么"是经典杀手）

### 物理准备（睡前做）

- [ ] **不要熬夜准备**——夜熬掉的状态，第二天面试会慢半拍
- [ ] **明天的衣服提前挂出来**（视频面试也要穿正装上半身——状态影响表达）
- [ ] **明天的水/咖啡/吃什么**提前想好——面试当天不要做"今天吃啥"这种小决策（决策疲劳是真的）
- [ ] **闹钟设两个**（手机 + 备用闹钟）

### 心理准备（睡前做）

- [ ] 给自己一段**自我对话**：
  > "明天的面试是双向校准——我也在评估这家公司。如果对方傲慢/不专业/价值观不合，我也可以选择拒。我不是来求 offer 的，我是来找一个互相 fit 的合作关系的。"
- [ ] **想象 3 个场景**：
  - 我答得很好的样子（增强 confidence）
  - 我被问到不会的样子 + 我的应对（"这个我没经验，但我猜是 X，对吗"）
  - 面试结束我说"谢谢这个深度的对话"的样子（埋下温暖的结束姿态）

## 面试前 1 小时

### 视频面试 setup（20 分钟）

- [ ] **网络备份**：手机开热点放旁边，主网断的瞬间能切
- [ ] **光线**：面对窗户或灯，不要背对（背光会让脸黑）
- [ ] **背景**：不杂乱（虚拟背景 OK 但会让你显得"不真实"，物理背景更好）
- [ ] **麦克风**：用专门的耳机麦，不要用电脑自带（自带的回音和环境音都重）
- [ ] **摄像头位置**：眼平 / 略高一点（往下俯拍显猥琐，往上仰拍显傲慢）
- [ ] **手机**：调静音 + 翻面（不要让通知影响）
- [ ] **饮用水**：杯子放手边
- [ ] **测试链接**：提前 15 分钟点开 Zoom/Tencent Meeting 测试音视频

### 现场面试 setup

- [ ] **提前 15-20 分钟到楼下**——给自己缓冲
- [ ] **不要提前 30+ 分钟到前台**——会让对方觉得"你太需要这个 offer"，反而降权
- [ ] **手机静音**
- [ ] **带一份打印简历**（即使对方有电子版——展示你认真）
- [ ] **带笔和便签**（记关键点，也给面试官好印象）

### 状态调节（10 分钟）

紧张是正常的——但**让紧张为你工作**：

- **生理调节**：4-7-8 呼吸（吸气 4 秒 / 屏息 7 秒 / 呼气 8 秒），重复 3 轮 = 副交感神经激活，心率立降。
- **姿势调节**：双臂上举或叉腰 2 分钟（power pose——是否真有效有争议但安慰剂效应也是效应）。
- **自我对话**：
  > "我紧张是因为我在意——这是好事。今天我去**展示**，不是去**证明**。"

紧张的根源是"我必须证明自己"——切换成"我来展示我是谁"——本质是**从对方视角切换到自己视角**。

## 面试中 · 节奏控制

### 第 1 分钟（首因效应黄金窗口）

- **进门/上线第一句**：眼神接触 + 微笑 + "你好，X 老师"
  - 不要先说"非常感谢这个机会"——那是结束时的话
  - 不要紧张到忘了自我介绍——准备好的"30s/60s/2min"按对方时间选

### 中间过程（节奏控制）

**3 个核心动作**：

#### ① 听 → 想 → 答（不要立刻答）

被问到问题，**停 1-2 秒**再答。这一停做了 3 件事：
- 显示你**在想**（不是背诵）
- 给自己**整理结构**的时间
- **降低你的语速**——稳定的语速 = 低 N（情绪稳定）信号

❌ "好的好的，让我想想——啊我们当时是这样的——"（紧张感外溢）
✅ [停 1.5 秒] "[你的回答用清晰的结构开头]"

#### ② 用"框架开场"答复杂问题

复杂问题不要直接讲故事——先给框架：

❌ "我做过这个项目，我们一开始是这样的..."

✅ "这个我想从 3 个角度讲：(1) 我们做了什么；(2) 我从中学到什么；(3) 这个判断在我后续怎么用。先讲第一个——..."

这一开场做对了 3 件事：
- 显示**结构化思维**
- 让面试官知道**听多久**——心理预期管理
- 给自己**记忆锚点**——讲到一半不会忘

#### ③ 用"我观察到 / 我判断 / 我的对策"3 段格式应对开放题

很多 PM 面试问开放问题（"你怎么看 [Agent] / [eval] / [Agentic RAG]"）——用这个 3 段格式：

```
"我观察到 [现象/事实——展示你看到了什么]——
我判断这是因为 [机理/原因——展示你的思考]——
我会做的事是 [对策/动作——展示你能落地]"
```

这一格式 = 现象 + 机理 + 动作 = 完整的 PM 思考链。

### 应对"我不会"的题

被问到不会的——**绝对不要说"我不知道"**就停。

正确做法：
1. **承认边界**："这个我没有直接经验"
2. **猜测 + 推理**："但如果让我猜，我觉得 [推理]——因为 [机理]"
3. **明确不确定性**："但这是我现场推理的判断，可能有偏差"
4. **反问对方**："你们实际怎么处理的？我蛮好奇"

这一套下来 = 不装会 + 展示推理能力 + 把对话延续。

### 应对"压力面"

如果面试官故意 push 你（"我觉得你这个回答不够深"），3 个反应：

❌ 慌：开始解释、找补、声音颤抖（暴露低稳定性）
❌ 怼：反驳对方（暴露低 A）
✅ 接：
> "你这个 push 我觉得有道理——具体是哪一块你觉得不够深？我再展开。"

这一接做对的：
- 不防御
- 显示你**能接 feedback**（高 C 信号）
- 把球踢回对方让 TA 具体化（你拿到追问方向）

## 面试后 · 当天

### 立刻做（面试结束 30 分钟内）

**写 retro**——趁记忆新鲜：

```markdown
## [公司][轮次] 面试 retro - [日期]

### 答得好的 3 题
1. [题] —— 因为 [...]
2. ...

### 答得糟的 3 题
1. [题] —— 我说了 X，但应该说 Y，因为 [...]
2. ...

### 面试官透露的关键信息
- 对方说 [...] —— 这告诉我 [...]

### 我对这家公司的判断（更新）
[...]

### 下一步
- [ ] follow-up 邮件 today
- [ ] [ 如果对方说"我们 X 天回复"——calendar 设个 reminder ]
```

### Follow-up 邮件（面试后 24 小时内）

跟进邮件**不是礼仪**——是**第二次塑造印象**的窗口。

#### 模板

```
Subject: 感谢今天的对话 - [你的名字]

[面试官名]：

非常感谢今天的对话。整场聊下来我对 [团队 / 这个岗位] 更兴奋了——尤其是聊到 [一个具体的对话点] 时，让我意识到 [一个具体的判断/感受]。

[关键段：补一个面试中没充分展开的点]
关于今天聊到的 [某个话题]，我面试中讲得不够清楚——我后来又想了想，我的完整看法是 [更深一层的回答]。希望这个补充对你的评估有帮助。

[关键段：表达想加入但不卑微]
基于今天的聊天，我对这个机会非常有信心 fit。如果有任何后续步骤，期待对方的下一步沟通。

再次感谢你今天花的时间。

[你的名字]
```

#### 这封邮件做对的 5 件事

1. **个性化的 callback**——提到具体对话点（不是"今天聊得很好"这种废话）
2. **补一个深度回答**——把没充分展开的题再答一次。**这一段是金子**——很多面试官在评估时会回看这封邮件，第二次回答比第一次更深 = 在评估时刻意提升你的分。
3. **不卑微**——"非常感谢您给我这次机会"是低姿态，"我对这个机会有信心 fit"是平等姿态
4. **互惠原则的应用**——你给了一个深度补充（输出），对方更可能给你下一步（输入）
5. **激活对方"如果他来"画面**——"如果有任何后续步骤" = TA 已经在想象有你的下一步

#### 反例

❌ "尊敬的 X 老师，非常感谢您今天给我这次面试机会，我会继续努力的。" —— 太低姿态，零信息密度。
❌ "我觉得我表现还不错，希望能进入下一轮。" —— 自我评估，不专业。
❌ 没发跟进邮件 —— 错失 50% 的二次印象塑造窗口。

#### 邮件发送时机

- 面试当天发：显示热情（推荐）
- 面试后第 2 天发：显示从容（也 OK）
- 第 3 天后：太晚，对方记忆已经模糊

## 面试后 · 中长期 follow-up

### 等待期（拿 offer 之前）

如果对方说"X 天回复"，X 天到了还没回 → **可以发一次轻 follow-up**：

```
[面试官名]：

不打扰。上次面试后的 [X 天] 大概是回复时间，我想跟进一下进展。
我目前的状态：[手上有几个其他 offer 或没有 — 如果有，提一下时间压力]。

[你的名字]
```

**不要**：
- 每天发邮件催
- 在邮件里抱怨
- 假装手上有 offer（万一对方查穿，灾难）

### 拿到 offer 后

见 offer-craft.md 的 counter 话术。

### 没拿到 offer

**发一封感谢 + 求反馈邮件**：

```
[面试官名]：

谢谢你和你团队这段时间的对话。理解你们的决定。

如果方便的话，可以给我一些反馈吗？我想了解我哪些地方做得不够，下次能做得更好。

如果未来你的团队有合适的机会，欢迎再联系。

[你的名字]
```

为什么要发：
- **可能拿到反馈**（即使不全，一两条也值钱）
- **维护长期关系**——这一行业很小，2 年后可能再遇
- **显示你的成熟度**——能从拒中学到东西的人很少
